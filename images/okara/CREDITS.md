# Okara photographs — sources and licences

Every file in this folder is a real photograph of Okara District, Punjab, Pakistan,
downloaded from [Wikimedia Commons](https://commons.wikimedia.org/wiki/Category:Okara)
and re-encoded for the web. **No AI-generated imagery and no stock housing photography.**

All of these are licensed **CC BY-SA** (3.0 or 4.0), which requires attribution and
share-alike. The credits are shown publicly in the "Photograph credits" section at the
bottom of `index.html` — if you swap images in or out, update that section too.

Four files had a burned-in camera date stamp, which was cropped off the bottom edge:
`okara-city-entrance`, `okara-farmland-chak-56`, `okara-cricket-stadium`,
`okara-canal-shergarh-rd`.
